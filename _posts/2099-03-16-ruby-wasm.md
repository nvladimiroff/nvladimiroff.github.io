Wanna ditch JavaScript and replace your frontend with Ruby? Me too! Unfortunately, Ruby isn't there yet. But if you're willing to trek through some untrodden paths, I'll show you how to create the most basic single page application:

```ruby
app = JS.global[:document].getElementById("app")
app[:innerHTML] = '<h1>Hello world!</h1>'
```

High-tech!

## The toolchain

You can run Ruby in your browser by using [ruby-wasm](https://github.com/ruby/ruby.wasm).
